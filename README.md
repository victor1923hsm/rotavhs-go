# RotaVHS Go — protótipo de teste

PWA para o entregador da Shopee SPX: importar a planilha, conferir, otimizar a ordem **estimada**, rodar a rota com o mapa, marcar entregas e ver o custo estimado de combustível.

**Protótipo publicado:** https://victor1923hsm.github.io/rotavhs-go/

- É um **PROTÓTIPO DE TESTE**, só com **dados fictícios** (endereços e códigos inventados).
- Na versão publicada, a importação usa uma planilha fictícia; a planilha real só é lida na versão local, dentro do aparelho, e nunca é enviada a lugar nenhum.
- Distâncias, tempos e custos são **estimados** (linha reta × fator urbano). O GPS real ainda não está ligado.

Rodar no PC: `npm install`, `npm test`, `npm run build`, `npm run preview`.
Documentação: `docs/` (comece por `docs/CONTINUAR-PROJETO.md`).
